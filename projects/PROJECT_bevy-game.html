El programmer

So let's start another reasonable project which I will definitely finish. I wanted to create a game but not in Unity or Unreal Engine. This would be 'too easy' I'd say but really, I just want to code a game in Rust along with Bevy. This is all completely unnesessary by the way! Rust looked cool, Bevy also got my attention, and now here we are. Me along with Raf, a friend of mine, started on the project.

It started off quite rough because I had almost no experience in Rust and Raf was on no better grounds. A bare movement script got made in two days during the exam periods of both Raf and me! Quite the pace we've got going it looked like until you notice the code was mostely copy-pasted from the example-site on Bevy, we wouldn't want to reinvent the wheel with our code right. Well, I wanted to do it myself, so scrap the examples, no direct copy-pasting, we're making the game ourselves!

Another day went by and another movement script was made, on our own this time. It even has acceleration! At the time of writing this, we're contemplating how we're going to program the randomly-generated worlds themselves, this is still far into the future so we'll push this a bit further along the road. First up though is a tilemap for our sprites, next time I'm working I'm gonna take a look at how to do that, Raf already had an idea with Matrices.
